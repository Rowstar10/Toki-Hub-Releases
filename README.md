# Toki Hub

A launcher for Hu Taong and every version of it.

Download **Toki Hub.exe** from the [latest release](https://github.com/Rowstar10/Toki-Hub-Releases/releases/latest)
and double-click it: nothing to install, and no account needed. Windows may say it "protected your
PC", because the exe isn't code-signed: click **More info**, then **Run anyway**. It updates itself.

On an Android phone or tablet, download **Toki-Hub-android.apk** from the same release and open it.
